# История разработки BeGenSt · PDF&Pic2RFA (по чату с Claude, сентябрь–октябрь 2026)

## Исходная задача
Открытый плагин ArchSmarter **FamFab** (Revit, семейство по картинке через Claude API):
1. проверить работоспособность — в VS не появлялась вкладка, ошибка **CS0234**;
2. переработать: семейство из **2D векторного PDF-чертежа (≥ 2 вида)**, подключение не только Claude, но и **Gemini**.

## Версии и решения

| Версия | Что сделано |
|---|---|
| 0.x (FamFab fix) | CS0234/System.Text.Json на net48: ссылка System.Net.Http + пакет System.Text.Json; TLS 1.2; резолв сборок из папки надстройки. PDF как вход (Claude document / Gemini inline_data), Gemini-клиент, выбор провайдера. |
| — | Циклон (`TestDrawings/Cyclone_reference.json`): тела вращения для конуса, параллельные плоскости бленд, тангенциальный вход (внутренняя стенка по касательной, наружная — 45° с касательной), опорные лапы ~200 мм только внизу цилиндра, фланец входа 800 мм от оси, высота 860 (цепочка 340+430+90). Причина «пропавшего конуса» — старая DLL (Revit держал файл). |
| 1.0.0 | Переименование: вкладка **BeGenSt**, панель **PDF&Pic2RFA**, кнопки PreGenerate / RFAGen; тёмно-серый UI с оранжевым/жёлтым/белым; до 3 файлов (PDF/JPG/PNG); техданные из PDF → параметры (встроенные Model/Manufacturer/…, типизированные масса/кВт/м³/ч…, текстовые); проверка исходных данных с диалогом конфликтов; проверка модели перед предпросмотром (GeometryInspector + ИИ). MSI на WiX v5 для Revit 2024–2027 (`BuildInstaller.cmd`). Навык `rfagen-json-from-drawing` — JSON без API-ключа. |
| 1.1.0 | Провайдер **DeepSeek** (OpenAI-совместимый). PDF не принимает → локальная растеризация PDF (Docnet.Core/pdfium) + текстовый слой. Итог теста: ~13 элементов против ~30 у Claude/Gemini (картинка ужимается до ~1300 px). |
| — | Анализ альтернатив: `docs/BeGenSt_AI_models_comparison.xlsx` (Qwen, GPT-5.6 Luna, Gemini Flash/Lite, Mistral, GLM…). |
| 1.2.0 | DeepSeek заменён на **Alibaba Qwen** (qwen3.7-plus, страницы PDF 3600 px, до 16 Мп на изображение), поле Base URL (ключи привязаны к региону). |
| 1.2.1 | Модели с «/» в имени идут в **OpenRouter** (`https://openrouter.ai/api/v1`) с отдельным ключом OpenRouter. |
| 1.2.2 | «Missing Authentication header»: очистка ключа от невидимых символов, типизированный заголовок Authorization, диагностика 401 (маска ключа). Бесплатные модели OpenRouter: qwen3.8-27b:free снят, inkling-small:free — только для агент-приложений (не обходим). |
| 1.3.0 | Кнопка **Purge** (неиспользуемые элементы, несколько проходов, сохранение со сжатием — размер файлов уменьшился в 3–4 раза). Галочки: **параметры семейства/шаблона** (язык ru/en определяется автоматически) и **ФОП** (общие параметры из .txt). Новые иконки (тёмно-серый/синий/жёлтый); PreGenerate → **Generate**. Русские опорные плоскости шаблона не удаляются. |
| 1.3.1 | Сопоставление/перевод параметров и для **Load JSON** (ИИ при наличии ключа, иначе словарь); переименование в выражениях. **Тип семейства** = имя семейства из плагина. **Описание** = «Наименование» + технические характеристики. Purge — первая кнопка. |
| 1.4.0 | **TypeGen**: семейство с несколькими типами по таблице каталога (окно TypeGen: чтение таблицы ИИ, редактируемая таблица, фигура/префикс/шаблон имени, один параметрический шаблон, проверка L/H по каждому типу, 3D-предпросмотр типа, Save/Load catalog JSON). Генератор: типы, параметры типа, наборы геометрии с видимостью (BGS_Набор / BGS_Видимость_NN), отверстия «holes» с круговым массивом, переключатель привода «Показать_привод», автоматический Purge. Подстановка параметров в выражениях — по целым идентификаторам. Эталон: клапан КЗРр 25с947нж ГК «Авангард», 40 типов. |
| 1.4.1 | После теста TypeGen: **таблица выбора** BGS_Catalog (CSV, size_lookup по DN+PN с проверкой каждого типа, откат к значениям при несовпадении) + типы на каждую строку; **2 трубных коннектора** (Global) на ±L/2 на скрытых дисках, длина привязана к L, диаметр = DN; категория «Обобщённые модели» → **«Арматура трубопроводов»**, тип детали «Клапан — врезка»; поэлементный круговой массив `pattern`; детализированный эталон клапана (27 элементов: патрубки-конусы, корпус из двух конусов, крышка со шпильками, бугель, привод с двигателем и маховиком); вспомогательные параметры переименованы в ASCII (BGS_Set, BGS_Vis_NN, BGS_Conn_*, BGS_Zero). Замечание: в тесте была установлена 1.3.1 — сборка 1.4.0 не выполнялась. |
| 1.4.2 | TypeGen: полые выдавливания (отверстие корпуса) всех наборов были видны в редакторе семейств, в т.ч. в «Видимости просмотра» — у пустот нет параметра «Видимость». Теперь все пустоты после вырезания скрываются на всех видах семейства (вырезы сохраняются; «Показать скрытые элементы» — увидеть их). |
| 1.4.3 | По отчёту генерации: созданы все 805 элементов (35 × 23 набора; «805/621» — ожидаемое число не учитывало копии массивов, исправлено). Параметры шаблона D2, D3, L, n, d, H были с формулами / только для чтения → значения каталога не записывались, формулы коннекторов и size_lookup отклонялись. Теперь столбцы каталога приводятся к обычным параметрам типа (формула снимается, экземпляр → тип, «отчётный» → обычный, с записью в отчёт); целочисленные столбцы (DN, n) — числовые для size_lookup; запасной вариант коннекторов — значения по типам; в отчёте — текст отклонённой формулы и типы ключей. |
| 1.4.4 | Тест в существующем семействе Avangard.rfa (свои таблицы выбора LTG, ЗРК_Геометрия, РК_Приводы, РК_Регада, параметры экземпляра с size_lookup): ошибки «Не удалось сформировать выдавливание» при смене типа и чужой привод. Теперь: предупреждение перед генерацией в семейство с собственным содержимым (вложенные семейства, таблицы выбора, размеры) с рекомендацией нового семейства; журнал ошибок Revit (FailureLog) с именами созданных элементов в отчёте; таблица выбора и формулы size_lookup — отдельной транзакцией после основной, с вариантами формулы и записью причины отказа; отчёт сохраняется после Purge. **Purge → «Full clean before generation»**: кроме неиспользуемых элементов удаляет собственное содержимое семейства — геометрию, коннекторы, вложенные семейства, размеры, линии, опорные линии и свои опорные плоскости, таблицы выбора и формулы size_lookup (параметры сохраняются); то же предлагается в TypeGen перед генерацией. |

## Открытые вопросы / идеи
* Тест 1.3.1: Load JSON + ФОП (русский) с ключом и без ключа.
* Платные модели OpenRouter для теста: `thinkingmachines/inkling-small`, `qwen/qwen3.8-27b`.
* OpenAI GPT-5.6 Luna (нативный PDF) — отдельный клиент, если появится ключ.
* Refine в предпросмотре пока не передаёт инструкции сопоставления параметров (имена уже в JSON).
