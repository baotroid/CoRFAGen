# BeGenSt PDF&Pic2RFA 1.4.4

Установщик для Revit 2024–2027 (заменяет предыдущие версии). Перед установкой закройте Revit.

## TypeGen — семейство с типоразмерами по каталогу (1.4.0–1.4.4)
* Чтение таблицы типоразмеров из каталога ИИ (объединённые ячейки PN разворачиваются), редактируемая таблица,
  выбор фигуры, шаблон имени типа `{Префикс} {Обозначение} DN{DN} PN{PN}`, Save/Load catalog JSON.
* Один параметрический шаблон, проверка L/H по каждому типу, 3D-предпросмотр любого типа.
* В Revit: тип на каждую строку, наборы геометрии с видимостью по типу, отверстия фланцев массивом, поэлементные
  круговые массивы (шпильки, стойки бугеля), привод с переключателем экземпляра «Показать_привод».
* Таблица выбора BGS_Catalog и формулы size_lookup по DN+PN (с проверкой каждого типа).
* Два трубных коннектора (Global) на ±L/2, диаметр = DN; категория «Арматура трубопроводов», тип детали «Клапан — врезка».
* Существующие параметры-столбцы приводятся к обычным параметрам типа; пустоты скрываются на видах семейства.
* Журнал ошибок Revit с именами элементов в отчёте `%AppData%\BeGenSt\RFAGen\Logs\…-types-generation-report.txt`.
* Эталон: `TestDrawings/Avangard_KZRr_25s947nzh_catalog.json` — клапан КЗРр 25с947нж ГК «Авангард», 40 типов.

## Purge
* Новый режим **Full clean before generation**: удаляет геометрию, коннекторы, вложенные семейства, размеры, линии,
  собственные опорные плоскости, таблицы выбора и формулы size_lookup (параметры сохраняются), затем Purge.
  TypeGen предлагает его сам, если в семействе есть такое содержимое.

## Навык Claude rfagen-json-from-drawing
* Раздел о каталожных семействах (TypeGen): шаблон, детализация, `pattern`, `lookup`, `connectors`;
  `rfagen_check.py` проверяет каждый тип каталога (X = L, верх = H, отверстия во фланце).
